# ことだま占い — 設計書

**作成日:** 2026-05-05  
**ステータス:** 承認済み

---

## 概要

姓名（漢字・読み）を入力すると、AIが毎日のリアルタイム統計データ（天気・気圧・曜日・六曜など）と名前の特性を掛け合わせ、「今日のあなた」を占い形式で生成するWebアプリ。

**ターゲット:** 一般公開（特に20〜40代女性）  
**コアバリュー:** AI×統計×毎日使える手軽さ

---

## 機能要件

### 基本機能

| 機能 | 説明 |
|------|------|
| 名前登録 | 姓・名（漢字）・読み（ひらがな）・居住地域を初回のみ入力。端末（セッション）に保存 |
| 今日の占い生成 | 名前分析＋今日の統計データをClaude APIに渡し、占い文を自動生成 |
| 運勢スコア表示 | 総合・恋愛・仕事・金運を⭐1〜5で表示 |
| ラッキー情報 | ラッキーカラー・時間帯・場所・数字をAIが生成 |
| シェア機能 | X（Twitter）・LINEへの共有テキストを生成。友達と相性占いができる導線付き |

### 毎日来る仕掛け（エンゲージメント機能）

| 機能 | 詳細 |
|------|------|
| 🔥 ストリーク | 連続チェック日数をカウント。3日・7日・30日でバッジ表示 |
| ⏰ リセットタイマー | 毎日23:59リセット。残り時間をカウントダウン表示。残り1時間を切ると赤く強調 |
| 🌅 朝イチ限定メッセージ | 1日1回のClaude API呼び出し時に朝イチメッセージも同時生成してキャッシュ。表示／非表示はアプリ側で時間判定（00:00〜11:59のみ表示）|

## 画面構成

### 画面1: 名前登録（初回のみ）

- 入力項目: 姓（漢字）、名（漢字）、読み（ひらがな）、居住地域
- 入力後はセッションステートに保存し、次回以降は結果画面へ直接遷移
- デザイン: パステルピンク×ラベンダー、角丸カード

### 画面2: 今日の占い結果（毎日更新）

上から順に:

1. **ストリークバー** — 連続日数 + 達成バッジ
2. **リセットタイマー** — 残り時間（残り1時間未満で赤色）
3. **朝イチ限定バナー** — 午前中のみ表示。午後以降は「明日の朝もお楽しみに」に切替
4. **日付・あいさつヘッダー** — 日付・曜日・天気・気圧・名前を表示
5. **運勢スコアカード** — 総合・恋愛・仕事・金運の⭐表示
6. **言霊分析バブル** — 名前の漢字特性×今日のデータの統計根拠コメント
7. **今日のメッセージバブル** — AIが生成する占い本文
8. **ラッキーストリップ** — カラー・時間・場所・数字
9. **シェアボタン** — X / LINE共有

## データフロー

```
名前入力（初回）
    ↓
名前分析モジュール
  - 漢字の意味・部首・画数（独自辞書テーブル）
  - 読みの音感分類（開放音 / 内向音）
  - 姓名の画数合計（姓名判断ロジック）
    ↓
統計データ取得（毎日自動）
  - 天気・気温・気圧・湿度（Open-Meteo API 無料）
  - 曜日・月・六曜・二十四節気（Pythonで算出）
  - 祝日フラグ（jpholiday ライブラリ）
    ↓
Claude APIプロンプト組み立て
  - システムプロンプト: 占い師キャラクター設定（ことだま占い）
  - ユーザープロンプト: 名前分析結果 + 今日の統計データを渡す
  - 出力形式: JSON（言霊分析・今日のメッセージ・ラッキー情報・⭐スコア）
    ↓
Streamlit画面に表示
```

## 技術スタック

| 役割 | 技術 |
|------|------|
| フロントエンド / バックエンド | Python + Streamlit |
| AI生成 | Claude API（anthropic SDK）`claude-haiku-4-5` |
| 天気データ | Open-Meteo API（無料・APIキー不要） |
| 六曜・祝日 | `jpholiday`、`ephem` または独自算出 |
| 名前分析 | 独自辞書（常用漢字2136字の意味・画数テーブルをPython dictで実装）|
| 状態保存 | `st.session_state` + JSONファイル（ストリーク管理）|
| シェア | Xシェアリンク生成（`https://x.com/intent/tweet?text=...`）+ クリップボードコピー |

---

## 非機能要件

- **レスポンス:** Claude API呼び出しは1回/日（結果をキャッシュ。同日2回目以降はキャッシュを表示）
- **コスト:** Haiku使用でユーザー1人あたり約0.01円/日
- **プライバシー:** 姓名・読みはClaude APIのプロンプトに含まれてAnthropicに送信される。Anthropicのプライバシーポリシーに準拠。それ以外の保存先はローカルJSONのみ
- **対応環境:** PC / スマートフォンブラウザ（Streamlitのレスポンシブ対応）
