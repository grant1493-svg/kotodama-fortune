# ことだま占い — 設計書

**作成日:** 2026-05-05  
**ステータス:** 承認済み（Flask＋広告収益化対応版）

---

## 概要

姓名（漢字・読み）を入力すると、AIが毎日のリアルタイム統計データ（天気・気圧・曜日・六曜など）と名前の特性を掛け合わせ、「今日のあなた」を占い形式で生成するWebアプリ。Google AdSenseで広告収益化する。

**ターゲット:** 一般公開（特に20〜40代女性）  
**コアバリュー:** AI×統計×毎日使える手軽さ  
**収益モデル:** 無料公開 ＋ Google AdSense広告

---

## 機能要件

### 基本機能

| 機能 | 説明 |
|------|------|
| 名前登録 | 姓・名（漢字）・読み（ひらがな）・居住地域を初回のみ入力。ブラウザのlocalStorageに保存 |
| 今日の占い生成 | 名前分析＋今日の統計データをClaude APIに渡し、占い文を自動生成 |
| 運勢スコア表示 | 総合・恋愛・仕事・金運を⭐1〜5で表示 |
| ラッキー情報 | ラッキーカラー・時間帯・場所・数字をAIが生成 |
| シェア機能 | X（Twitter）・LINEへの共有テキストを生成。友達と相性占いができる導線付き |

### 毎日来る仕掛け（エンゲージメント機能）

| 機能 | 詳細 |
|------|------|
| 🔥 ストリーク | 連続チェック日数をカウント。3日・7日・30日でバッジ表示。localStorageに保存 |
| ⏰ リセットタイマー | 毎日23:59リセット。残り時間をJavaScriptでカウントダウン表示。残り1時間を切ると赤く強調 |
| 🌅 朝イチ限定メッセージ | 1日1回のClaude API呼び出し時に朝イチメッセージも同時生成してキャッシュ。表示／非表示はJS側で時間判定（00:00〜11:59のみ表示）|

### 法的対応ページ（広告収益化必須）

| ページ | 内容 |
|--------|------|
| プライバシーポリシー | Cookie使用・AdSense・Claude APIへのデータ送信を明記 |
| 特定商取引法に基づく表記 | 運営者名・連絡先・サービス概要を記載 |
| 免責事項 | 「AIによる娯楽コンテンツ。占い結果は参考程度に」を明記 |

## 画面構成

### 画面1: 名前登録（初回のみ）

- 入力項目: 姓（漢字）、名（漢字）、読み（ひらがな）、居住地域
- 「入力した名前はAI生成のためAnthropicのサーバーに送信されます」の同意文を表示
- 入力後はlocalStorageに保存し、次回以降は結果画面へ直接遷移
- デザイン: パステルピンク×ラベンダー、角丸カード

### 画面2: 今日の占い結果（毎日更新）

上から順に:

1. **ストリークバー** — 連続日数 + 達成バッジ
2. **リセットタイマー** — 残り時間（残り1時間未満で赤色）
3. **広告枠（上部）** — Google AdSense レスポンシブ広告
4. **朝イチ限定バナー** — 午前中のみ表示。午後以降は「明日の朝もお楽しみに」に切替
5. **日付・あいさつヘッダー** — 日付・曜日・天気・気圧・名前を表示
6. **運勢スコアカード** — 総合・恋愛・仕事・金運の⭐表示
7. **言霊分析バブル** — 名前の漢字特性×今日のデータの統計根拠コメント
8. **今日のメッセージバブル** — AIが生成する占い本文
9. **広告枠（中部）** — Google AdSense インフィード広告
10. **ラッキーストリップ** — カラー・時間・場所・数字
11. **シェアボタン** — X / LINE共有
12. **フッター** — プライバシーポリシー / 特定商取引法 / 免責事項 リンク

## データフロー

```
名前入力（初回）→ localStorage保存
    ↓
名前分析モジュール（Python）
  - 漢字の意味・部首・画数（独自辞書テーブル）
  - 読みの音感分類（開放音 / 内向音）
  - 姓名の画数合計（姓名判断ロジック）
    ↓
統計データ取得（毎日自動）
  - 天気・気温・気圧・湿度（Open-Meteo API 無料）
  - 曜日・月・六曜・二十四節気（Pythonで算出）
  - 祝日フラグ（jpholiday ライブラリ）
    ↓
Claude APIプロンプト組み立て（1回/日・サーバーでキャッシュ）
  - システムプロンプト: ことだま占い師キャラクター設定
  - ユーザープロンプト: 名前分析結果 + 今日の統計データ
  - 出力形式: JSON（言霊分析・今日のメッセージ・朝イチメッセージ・ラッキー情報・⭐スコア）
    ↓
Flask → Jinja2テンプレートでHTML描画
（カウントダウン・ストリーク・朝イチ表示切替はJavaScriptで処理）
```

## 技術スタック

| 役割 | 技術 |
|------|------|
| Webフレームワーク | Python + Flask |
| テンプレートエンジン | Jinja2 |
| フロントエンド | HTML / CSS / JavaScript（フレームワークなし） |

| 状態保存 | ブラウザ localStorage（名前・ストリーク）+ サーバーキャッシュ（占い結果） |
| 広告 | Google AdSense（レスポンシブ広告 + インフィード広告） |
| シェア | Xシェアリンク（`https://x.com/intent/tweet?text=...`）+ クリップボードコピー |
| デプロイ | Render / Railway（無料枠でFlask対応）|

## 非機能要件

- **レスポンス:** Claude API呼び出しは1回/日（サーバー側で日付＋名前ハッシュをキーにキャッシュ。同日2回目以降はキャッシュを返す）
- **コスト:** Haiku使用でユーザー1人あたり約0.01円/日
- **プライバシー:** 姓名・読みはClaude APIのプロンプトに含まれてAnthropicに送信される。Anthropicのプライバシーポリシーに準拠。入力同意文を登録画面に表示する
- **広告表示:** AdSense審査通過後に広告コードを `<head>` に挿入。Jinja2のベーステンプレートで一元管理
- **Cookieバナー:** AdSense利用のためCookie使用の告知バナーを初回表示
- **対応環境:** PC / スマートフォンブラウザ（CSSメディアクエリでレスポンシブ対応）
