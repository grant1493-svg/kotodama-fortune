# 作業履歴ビューアー — デザインドキュメント

**日付**: 2026-05-22  
**ステータス**: 承認済み

## 概要

デスクトップに配置するショートカット（`履歴更新.bat`）をダブルクリックするだけで、
gitコミット履歴と保存済み会話まとめファイルの一覧をブラウザで表示できるHTML生成ツール。
各履歴項目からブラウザ表示・フォルダ表示・Claude Code起動の3アクションが可能。

## ファイル構成

```
デスクトップ/
├── 履歴更新.bat          ← エントリーポイント。ダブルクリックで履歴更新＋ブラウザ起動
├── history.html          ← 生成された履歴一覧（手動でも開ける）
└── launch_claude.bat     ← Claude Code起動用（history.htmlのボタンから呼ばれる）

C:\Users\admin\.local\bin\
└── generate_history.ps1  ← HTML生成ロジック本体（PowerShell）
```

## データソース

| 種別 | 内容 | 取得方法 |
|------|------|---------|
| gitコミット履歴 | ハッシュ・日時・メッセージ（最新20件） | `git -C C:\Users\admin\.local\bin log --oneline --format=...` |
| 会話まとめファイル | .html / .md ファイル | `C:\Users\admin\.local\bin\` 直下のファイル一覧 |

## HTML表示仕様

- ダークテーマ、1280px幅対応、横スクロールなし
- git履歴セクションと会話まとめセクションを縦に並べて表示
- **gitコミット項目**に表示するボタン:

| ボタン | 動作 |
|--------|------|
| フォルダを開く | `file:///C:/Users/admin/.local/bin/` をエクスプローラで開く |
| Claudeで続きから | デスクトップの `launch_claude.bat` を呼び出す |

- **会話まとめ項目**（.html ファイルのみ）に表示するボタン:

| ボタン | 動作 |
|--------|------|
| ブラウザで開く | `file:///` リンクで .html をブラウザで開く |
| フォルダを開く | `file:///C:/Users/admin/.local/bin/` をエクスプローラで開く |
| Claudeで続きから | デスクトップの `launch_claude.bat` を呼び出す |

- .md ファイルは会話まとめセクションに名前のみ表示（ブラウザ表示ボタンなし）

## Claude Code起動戦略

`launch_claude.bat` の内容:
```batch
cd /d C:\Users\admin\.local\bin
start cmd /k claude
```
プロジェクトフォルダでClaude Codeを起動する。会話まとめのコンテキストは
ユーザーが手動でClaudeに貼り付ける想定（自動引き渡しはスコープ外）。

## エラーハンドリング

- git コマンドが失敗した場合 → "git履歴取得に失敗しました" と表示してスキップ
- 会話まとめフォルダにファイルがない場合 → "会話まとめファイルはありません" と表示
- HTML生成スクリプト実行失敗時 → .bat のコンソールエラーメッセージで通知

## 更新タイミング

手動（`履歴更新.bat` を叩くたびに最新化）。自動更新・常駐プロセスはなし。

## スコープ外

- 自動スケジュール更新
- 複数プロジェクトへの対応
- 会話まとめの内容をClaude Codeに自動引き渡し
