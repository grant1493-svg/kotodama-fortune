# LINE タスク抽出ツール — 設計書

**作成日:** 2026-04-26  
**ステータス:** 承認済み

---

## 概要

LINEのグループチャット履歴（.txtエクスポート）をClaude APIに渡し、会話中のタスク・依頼・指示を自動抽出して、ブラウザで使える見栄えのよいHTMLタスク表を生成するPython CLIツール。

---

## アーキテクチャ

```
LINEトーク履歴.txt
        ↓
  [1] パーサー
      ・日時・送信者・本文を1行ずつ読み取る
      ・スタンプ・画像などの非テキストを除外
        ↓
  [2] Claude API呼び出し
      ・会話全体を渡して「タスクをJSON形式で返して」
      ・長いログは自動分割して複数回APIを呼ぶ
      ・重複タスクを後処理でまとめる
        ↓
  [3] HTML生成
      ・JSONのタスクリストを表に整形
      ・優先度で行を色分け（高=赤・中=黄・低=緑）
      ・tasks_YYYYMMDD.html として保存
```

### 使い方

```bash
python line_tasks.py "トーク履歴.txt"
# → tasks_20260426.html が生成される
```

### 必要なもの

- Python 3.8以上
- `anthropic` パッケージ（`pip install anthropic`）
- Anthropic APIキー（環境変数 `ANTHROPIC_API_KEY`）

---

## 入力仕様

### LINEエクスポート形式

```
2026/04/20(月) 10:32  田中  見積書って今週中に出せますか？
2026/04/20(月) 10:35  課長  はい、木曜までに営業部へ提出してください
2026/04/20(月) 10:40  田中  わかりました
[スタンプ]                 ← 無視する
```

パーサーは以下を除外する：
- `[スタンプ]`
- `[写真]`
- `[動画]`
- `[ファイル]`
- その他非テキスト行

## Claude API プロンプト設計

```
以下はLINEのグループチャット履歴です。
会話の中からタスク・依頼・指示を抽出し、
以下のJSON形式で返してください。

{
  "tasks": [
    {
      "content": "見積書を営業部に提出する",
      "assignee": "田中",
      "deadline": "4/28",
      "priority": "高",
      "speaker": "課長",
      "datetime": "2026/04/20(月) 10:35"
    }
  ]
}

期限が明示されていない場合は "未定"、
担当者が不明な場合は "未定" としてください。

--- 会話ログ ---
（LINEログ本文）
```

- モデル: `claude-sonnet-4-6`
- 長いログの扱い: 約10万文字を超えた場合は自動分割・複数回呼び出し

## 出力仕様

### HTML テーブル列構成

| 列 | 内容 | 備考 |
|---|---|---|
| # | 連番 | — |
| タスク内容 | 何をするか | AI抽出 |
| 担当者 | 誰がやるか | AI抽出（不明→「未定」） |
| 期限 | いつまでに | AI抽出（不明→「未定」） |
| 優先度 | 高・中・低 | AI抽出、色バッジ表示 |
| 進捗状況 | 未着手／進行中／完了 | HTMLで直接クリック変更 |
| 発言者 | 誰が指示したか | AI抽出 |
| 発言日時 | 元の発言日時 | — |

### JavaScript 動作仕様

**進捗状況の変更**
- 各行の「未着手」「進行中」「完了」をクリックで切り替え
- 状態は `localStorage` に自動保存（ブラウザを閉じても維持）

**完了タスクの移動**
- 「完了」にした瞬間、アニメーションで表下部の「✅ 完了済み」セクションへ移動
- 「完了済み」セクションは折りたたみ可能
- 「完了」を別の状態に戻すと「未完了タスク」に自動復帰

**その他の機能**
- 担当者・優先度でフィルタリング
- 印刷ボタン（`@media print` 対応）
- ヘッダーに生成日時・会話期間・総タスク数を表示

### 出力ファイル

`tasks_YYYYMMDD.html`（スクリプトと同じフォルダに保存）
